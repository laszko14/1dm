# Kontrakt integracji — 1DM+ 18.2 (plik APK właściciela)

Własna analiza DEX przesłanego lokalnie APK. Repozytorium NIE zawiera płatnego APK, kodu producenta ani sposobów obchodzenia licencji.

## Potwierdzone API po sygnaturach

- `acr.browser.lightning.view.LightningView.getId(): int` — ID karty
- `acr.browser.lightning.activity.TabsManager.size(): int` — liczba otwartych kart
- `TabsManager.getTabAtPosition(int): LightningView` — rzeczywista kolejność
- `TabsManager.getTabById(int): LightningView` — pobranie wg ID
- `TabsManager.getTabIndexById(int): int` — indeks wg ID
- `TabsManager.newTab(...)`, `removeTab(int)`, `saveState(): void`, `restoreState(int)`, `initializeTabs(...)`
- `TabsFragment` oraz `TabsFragment$LightningViewAdapter` — źródło listy i widoku kart

## Zaimplementowane osobno (niezintegrowane z oryginalnym APK)

- `TabGroupStore` — przypisania kart do grup, zapis nazw/ID.
- `TabGroupCoordinator` — filtr widocznych kart wg aktywnej grupy, natywna kolejność, sesja incognito wyłącznie w pamięci; nie zamyka WebView.
- `ReflectiveTabProvider` — odczyt kart przez potwierdzone sygnatury obiektu TabsManager.
- `TabGroupsDialog` — polskie dialogi Android do tworzenia, zmiany nazw, usuwania i przenoszenia kart.

## Ograniczenia i następny etap

1. Najpierw zweryfikować na urządzeniu stabilność `LightningView.getId()` po zamknięciu i ponownym otwarciu aplikacji. Deklaracja DEX NIE dowodzi trwałości ID.
2. Ustalić moment pełnego przywrócenia sesji. Nie wywoływać uzgadniania podczas częściowego restore — mogłoby skasować przypisania.
3. Przeprowadzić legalną integrację z panelem `TabsFragment`: akcja otwierająca dialog, filtry w adapterze, przypisywanie w zdarzeniach otwarcia/zamknięcia, osobna obsługa private.
4. Zbudować i przetestować osobną wersję testową, zachowując pobieranie plików i istniejące sesje.
5. Podpisu autora 1DM+ nie da się użyć do aktualizacji własnym APK. Nie obchodzić walidacji licencji.

Bez wykonania punktów 1–4 kompilowana biblioteka **nie staje się aplikacją 1DM+**.
